## 使用者可手動驗收

1. 執行 start.cmd，開啟 http://127.0.0.1:5174/。
2. 從設定「載入示範資料」，回月曆；點日期看下方行程，切週／日。
3. 按右下加號新增一筆，關掉頁面再開，應能讀回。
4. 新增待辦，按排程並儲存，應產生行程但仍保留待辦供勾選。
5. 切換深色主題，匯出 JSON 備份，再試匯入與取消。

## 手機操作後續補強

接續使用者「繼續執行」的要求，本輪修正 40px 的手機待辦勾選寬度、過小的換期按鈕與 42px 的短行程卡片，並加入編輯欄位焦點避讓。

新增三組瀏覽器驗收：320px 螢幕下的主要觸控區；390 × 400 的縮小可視高度中，備註、標題與地點聚焦後仍在儲存列下方且在畫面內；兩筆相隔五分鐘的短行程顯示高度足夠且互不重疊。縮小 viewport 僅用於測試可視高度變化，不代表實機軟鍵盤驗收。

本輪結果：17 項單元測試、26 組瀏覽器檢查通過，建置指紋 d4ccebf0a1bbcfd0。離線回歸曾因測試在取消表單後尚未等到路由完成便重載而失敗；補上日曆顯示的等待條件後，包含離線重載的完整流程通過。新增截圖 mobile-editor-reduced-height.png 與 mobile-short-events.png。
