# 產品規格

2026-11-05，本機第一版。

## 介面

手機直向優先：固定四項底部導覽（月曆、待辦、搜尋、設定），主要操作 44px 觸控高度。月曆保留七欄，只顯示日期與最多三個分類標記，點日期在下方呈現完整行程；桌面擴展為左右分欄。

月／週／日檢視共用選取日期與上一期／下一期／今天／日期跳轉。週檢視為一排日期選擇，加上所選日期的時間軸，避免七天時間欄擠在手機上。單日顯示當天行程與未完成到期待辦。

詳情與編輯頁隱藏主要導覽。編輯表單頂部儲存列吸附，取消或離頁時提示未儲存變更。文字以 HTML escape 呈現，備註保留換行。

手機操作補強：待辦勾選區與換期按鈕至少 44 × 44px；短時間行程卡片至少 48px 高，配置欄位時保留其實際顯示高度，避免相鄰短行程互相覆蓋。編輯欄位聚焦及可視高度變化時，調整捲動讓欄位避開頂部儲存列與可視範圍下緣。

## 行程語意

- 標題必填且最多 120 字；地點 240 字、備註 4000 字。
- 日期為裝置本地日期／時間，支援 1900–2199；無特定 IANA 時區欄位。
- 非全天結束時刻須晚於開始，可跨日，日期跨度至多 366 天。
- 全天結束日包含該日；一般行程在隔天 00:00 結束時，不占隔天。
- 重複可不重複／每天／每週／每月，結束日含當日；留白無限期，以查詢區間展開。每月缺少對應日期時略過。
- 系列使用同一識別碼，編輯與刪除作用於整個系列。尚無單次例外或此筆之後模式。

## 待辦、搜尋與分類

待辦有標題、可選截止日、分類與完成狀態。排程建立獨立行程並保存關聯，不自動完成待辦。刪行程清除關聯；刪待辦保留既有行程。搜尋展開選定區間內每一次行程，以標題／地點／備註比對，最大一年。

分類具穩定 id、名稱與色彩；刪除前必須沒有相關行程與待辦，至少保留一個分類。顏色有文字名稱輔助，無法只靠色彩辨識。

## 儲存與提醒

首次使用為空資料，不自行寫入示範行程。設定中可主動載入示範資料。JSON 匯入驗證完整資料後才顯示筆數與取代確認，取消不改資料。

提醒僅是開啟期間頁內提示；全域開關預設關閉。每 15 秒檢查，單次開啟避免相同行程重複提示，不補發超過 90 秒的過期提醒。不宣稱 App 關閉後仍能推播。

## 驗收

執行 `npm test`、`npm run build`、`npm run test:ui`。瀏覽器驗收涵蓋手機四種寬度與桌面兩種寬度、行程 CRUD、系列、待辦排程、搜尋、主題、分類、備份。真實觸控、鍵盤遮擋、主畫面安裝與背景提醒需另做實機驗收。
